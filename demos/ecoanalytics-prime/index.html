Fluxo da amostra

Como a amostra é acompanhada

  1. 1. Solicitação: dados ilustrativos são registrados.
  2. 2. Coleta: data fictícia é exibida no painel.
  3. 3. Recebimento: amostra entra na lista de acompanhamento.
  4. 4. Análise: resultados demonstrativos são gerados.
  5. 5. Relatório: resumo ilustrativo para impressão.

⚠ Nenhuma etapa é executada de fato. A ferramenta simula apenas a apresentação visual do fluxo.
