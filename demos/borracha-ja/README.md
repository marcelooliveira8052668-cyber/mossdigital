# Borracha Já — Demo MOSS Digital

**Segmento:** Borracharia  
**Função:** Formulário de triagem por veículo, serviço, bairro e observações, com envio assistido pelo WhatsApp.

## Como abrir
1. Extrair o ZIP inteiro, mantendo a estrutura de pastas.
2. Abrir `index.html` no Edge ou outro navegador.
3. Testar os botões e o WhatsApp.
4. Colocar fotografias em `assets/img/` conforme `FOTOS-PARA-OPENCODE.md`.

## Estrutura
- `index.html`: conteúdo e semântica HTML.
- `css/style.css`: layout exclusivo e responsividade, comentados em português.
- `js/script.js`: funções interativas, comentadas em português.
- `assets/img/placeholder.svg`: reserva local, para não aparecer imagem quebrada.
- `INTEGRACOES.md`: plano de domínio, hospedagem, Supabase, Pix e cartão.

## Limites
Projeto de portfólio, com marca e dados ilustrativos. Funções locais não são sistema multiusuário; dados de navegador podem ser apagados. Não contém pagamentos reais nem banco online. Não publicar sem aprovação.
