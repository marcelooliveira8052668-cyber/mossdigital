# Caçamba Certa — Demonstração MOSS Digital

**Segmento:** Locação de caçambas e coleta de entulho  
**Arquitetura visual:** Construtora industrial: tipografia condensada, composição diagonal e orçamento em destaque

## Como abrir
Extraia a pasta e abra `index.html` no Microsoft Edge. Não requer Node, npm ou servidor.

## Funcionalidades
- cálculo ilustrativo de diária
- seleção dinâmica de volume
- orçamento via WhatsApp


## Arquivos
- `index.html`: marcação da página, com comentários didáticos em português sempre que possível.
- `css/style.css`: identidade visual exclusiva e responsividade.
- `js/script.js`: interações e lógica sem frameworks.
- `assets/img/placeholder.svg`: marcador de fotos, para não quebrar o layout.
- `FOTOS-PARA-OPENCODE.md`: nomes exatos das fotografias e dimensões de referência.
- `INTEGRACOES.md`: guia prático de evolução para sistema integrado.

## Segurança e limites
Esta é uma **demo**, não um serviço comercial implantado. Dados e preços apresentados são fictícios. Onde existir `localStorage`, os dados ficam somente neste aparelho, sem login, criptografia de servidor, sincronização ou backup multiusuário. Não insira dados reais/sensíveis na demonstração.
