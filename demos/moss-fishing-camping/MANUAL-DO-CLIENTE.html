MOSS Fishing & Camping — manual

Modelo estático de loja demonstrativa. Não há loja, estoque, entrega, pagamento, banco de dados ou atendimento comercial de pesca configurados. A MOSS recebe apenas pedidos sobre criação de sites.

Instalação e testes

  1. Copie a pasta inteira e mantenha index.html, img/, os créditos e este manual juntos.
  2. Abra index.html no navegador ou use um servidor estático local, como python -m http.server 8080. Antes de entregar, teste busca, filtros, detalhes, carrinho, quantidades, formulário ilustrativo e telas de celular.
  3. O carrinho salva apenas IDs e quantidades no localStorage do navegador, sob a chave mossFishingCarrinho. O formulário mostra o pedido nesta aba e não envia os dados nem salva o nome/endereço.

Personalizar para um negócio real

  1. Troque marca, descrição, contatos, políticas, entrega e condições nos textos HTML. Confirme autorização das fotos e preserve os créditos se reutilizar as seis imagens ilustrativas.
  2. Substitua a lista dados no final de index.html por itens reais, com preço, disponibilidade, especificações e fotos do produto correto. As fotos desta demo são só referências de categoria, não mostram os 50 itens.
  3. Revise os links de WhatsApp, os botões e o processamento de enviarPedido. Nesta versão, o botão apenas exibe uma simulação; implementar pedidos reais requer novo fluxo, testes e consentimento do titular. Nunca encaminhe dados digitados para o WhatsApp da MOSS como se fosse uma loja de pesca.
  4. Se precisar de estoque/pedidos compartilhados, o modelo atual não tem banco conectado. Escolha uma solução de backend própria, autenticação e regras de acesso antes de prometer sincronização ou pagamentos. Não coloque senhas ou chaves privadas no HTML público.
  5. Publique a pasta como site estático com HTTPS; em hospedagem GitHub Pages, preserve os caminhos relativos. Confira o endereço ao vivo no celular. Se for um site real autorizado e pronto para pesquisa, revise o noindex do HTML.

Sem venda, compra, pagamento ou reserva real nesta demonstração. Para detalhes das imagens e licenças, veja créditos das fotos.
