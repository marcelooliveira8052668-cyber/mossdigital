# Doce Sob Medida — MOSS Digital

## Como abrir
Extraia o ZIP; dentro desta pasta abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Organização
- `index.html`: seções e formulários, com comentários em português.
- `css/style.css`: identidade visual própria e responsividade.
- `js/script.js`: funcionalidades e cálculos demonstrativos.
- `assets/img/`: fotografias ainda pendentes.
- `FOTOS-PARA-OPENCODE.md`: dimensões e nomes das imagens.
- `INTEGRACOES.md`: trilha de aprendizagem de integrações.
