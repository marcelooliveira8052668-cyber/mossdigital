Perguntas frequentes

Dúvidas comuns

Esta demonstração emite traduções juramentadas?

Não. Este é um site demonstrativo. O perfil apresentado é fictício e nenhuma credencial profissional real é assumida. Não são emitidos documentos com validade oficial.

Posso enviar meu documento pelo formulário?

Não. Esta página não recebe nem armazena arquivos. Para evitar exposição de dados pessoais, não anexe documentos reais. O formulário apenas valida campos e gera um resumo local.

Os valores do simulador são preços reais?

Não. São estimativas ilustrativas e configuráveis, usadas para demonstrar o funcionamento da calculadora. A tabela de preços de um serviço real depende de análise específica.

Os códigos de acompanhamento consultam dados reais?

Não. São códigos fictícios fixos nesta página. Nenhuma consulta a sistema externo é realizada.
