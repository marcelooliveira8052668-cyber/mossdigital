# Pedra Exata — Demo MOSS Digital

**Segmento:** Marmoraria e bancadas sob medida

**Visual único:** Arquitetura editorial; hero com fotografia dominante; materiais com seleção visual; orçamento técnico ilustrativo.

**Funções:** Seleção de materiais, cálculo geométrico de área, adicional por acabamento e resumo para WhatsApp.

## Como testar

1. Extraia a pasta inteira.
2. Abra `index.html` no Microsoft Edge.
3. Use menus e controles; não precisa instalar Node, npm ou frameworks.
4. Adicione fotos WebP conforme `FOTOS-PARA-OPENCODE.md`.
5. Leia `INTEGRACOES.md` para aprender hospedagem, domínio, Supabase, Pix e cartão.

## Observações importantes

- Marca, descrição e preços são ilustrativos. Não representam empresa existente.
- Os formulários apenas abrem o WhatsApp **(11) 94203-8103** para o usuário revisar e enviar.
- Pix, cartão, estoque real, login, backend e banco de dados **não estão habilitados**.
- Se houver `localStorage`, use **apenas informações fictícias**, pois a demo não possui proteção multiusuário nem backup.
- O site oficial MOSS Digital e o GitHub permanecem inalterados.
- **Ainda exige**: fotos reais licenciadas, teste visual do proprietário, dados do cliente e autorização para publicação.
