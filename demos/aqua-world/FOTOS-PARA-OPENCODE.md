# FOTOS PARA OPENCODE — Aqua World

## Regra
Use fotos reais com uso autorizado e mantenha os arquivos dentro de `assets/img/`.

## Arquivos previstos
- `assets/img/capa-aquario.webp`
- `assets/img/peixes-coloridos.webp`
- `assets/img/bomba-agua.webp`
- `assets/img/decoracao-aquario.webp`
- `assets/img/iluminacao-led.webp`

## Dica técnica
- Preserve a proporção dos cards.
- Use preferencialmente WebP.
- Se necessário, aplique `object-fit: cover` no contêiner da imagem.
- Não altere a altura dos cards só para acomodar a foto.

## Proporções e tamanhos recomendados
- Fotos de capa e de cards: comece com **1200 × 900 px**, em WebP.
- Na Sky Vision, use **1920 × 1080 px** para a capa em tela cheia.
- A proporção real de cada elemento é definida no CSS; não altere largura ou altura dos cards apenas para acomodar imagens.
- Use `object-fit: cover` e ajuste `object-position` quando o objeto principal ficar cortado.
- Comprima os arquivos mantendo nitidez e registre a licença/fonte de cada foto real.
- Evite logos, pessoas identificáveis e marcas registradas de terceiros sem autorização.

## Como usar
1. Salve os WebP com os nomes listados acima dentro da pasta `assets/img`.
2. Abra `index.html` no navegador. O JavaScript encontra os arquivos e substitui os marcadores automaticamente.
3. Confirme enquadramento em tela grande e pequena.
4. Nunca publique imagens sem confirmar sua origem e licença.
