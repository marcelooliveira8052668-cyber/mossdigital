# Casa do Queijo

Demo criada para o catálogo da MOSS Digital.

## Estrutura
- `index.html` — marcação principal.
- `css/style.css` — estilos exclusivos da demo.
- `js/script.js` — interações do site.
- `assets/img/placeholder.svg` — imagem padrão até inserir as fotos reais.
- `FOTOS-PARA-OPENCODE.md` — nomes esperados dos arquivos de imagem.
- `INTEGRACOES.md` — guia didático sobre domínio, hospedagem, Supabase, Pix e cartão.

## Observações
- WhatsApp configurado para (11) 94203-8103.
- Conteúdo demonstrativo, sem pagamentos integrados.
- Projeto pronto para receber fotos reais posteriormente.

## Como abrir no VS Code ou no navegador
1. Extraia o ZIP em uma pasta separada.
2. Abra a pasta no VS Code e localize `index.html`.
3. Dê dois cliques em `index.html` ou utilize uma extensão de servidor local.
4. Todos os arquivos CSS, JavaScript e a imagem de reserva são locais.
5. O WhatsApp utiliza conexão de internet para abrir o aplicativo.

## Atenção comercial
Esta é uma **demo funcional de portfólio**, não uma loja operando. Não oferece pagamentos reais, estoque, cadastro de clientes ou dados comerciais verificados.
Os formulários abrem uma mensagem no WhatsApp e dependem do envio pelo visitante.
