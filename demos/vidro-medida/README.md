# Vidro & Medida — Demo MOSS Digital

**Segmento:** Vidraçaria com estimador de projetos

## Abrir
Extraia o ZIP completo. Abra `index.html` no Edge ou Chrome, mantendo as pastas `css`, `js` e `assets` ao lado do HTML.

## Arquivos
- `index.html` — estrutura da página.
- `css/style.css` — layout independente, adaptado ao segmento.
- `js/script.js` — interações da demo.
- `assets/img/placeholder.svg` — marcador local para fotos.
- `FOTOS-PARA-OPENCODE.md` — nomes das imagens que podem ser adicionadas.
- `INTEGRACOES.md` — estudo de hospedagem, domínio, Supabase, Pix, cartão e APIs.

## Aviso
Protótipo para portfólio; não está conectado a um negócio real. Não possui cobrança automática, dados de pagamento ou sincronização remota. Não publicar no site oficial nem no GitHub sem aprovação.
