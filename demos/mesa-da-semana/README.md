# Mesa da Semana — Demo MOSS Digital (nº 63)

**Segmento:** marmitaria e encomendas semanais
**Identidade visual:** agenda semanal com navegação lateral e resumo fixo
**Recurso principal:** seletor de dias, tamanho da marmita, entrega e orçamento semanal pelo WhatsApp
**Contato:** (11) 94203-8103, autorizado para as demos.

## Como abrir
Extraia os arquivos, mantenha a estrutura das pastas e abra `index.html` no navegador.

## Organização
- `index.html` → HTML semântico da demo;
- `css/style.css` → identidade visual exclusiva;
- `js/script.js` → funcionalidade específica;
- `assets/img/placeholder.svg` → marcador seguro, até entrar a foto autorizada;
- `FOTOS-PARA-OPENCODE.md` → nomes, proporções e posições das imagens;
- `INTEGRACOES.md` → aula de domínio, hospedagem, Supabase, Pix/cartão e APIs.

## Avisos
- Todos os estabelecimentos, produtos, valores e disponibilidade são exemplos.
- As fotografias reais ainda não foram inseridas; utilize fontes com licença apropriada.
- O WhatsApp apenas abre uma mensagem. Não confirma compra, reserva, pagamento ou serviço.
- Nenhum dado do navegador é sincronizado com outros dispositivos. Armazenamentos locais, quando presentes, não são bancos de dados de produção.
- Não publicar sem revisão e autorização do proprietário.
