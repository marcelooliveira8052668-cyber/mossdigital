# Fotos para Lista Certa

Por enquanto, as imagens são **espaços de reserva**, não fotos reais do negócio.

Insira as fotos na pasta `assets/img/` com exatamente os nomes abaixo. O JavaScript reconhece automaticamente o arquivo quando ele existir, sem modificar o card.

- `capa-papelaria.webp` — Mesa de materiais escolares — orientação: 5:3.4 (ex.: 1100×750)
- `caderno.webp` — Caderno simples — orientação: 1:1 (ex.: 600×600)
- `lapis.webp` — Lápis grafite — orientação: 1:1 (ex.: 600×600)
- `caneta.webp` — Caneta azul — orientação: 1:1 (ex.: 600×600)
- `borracha.webp` — Borracha branca — orientação: 1:1 (ex.: 600×600)
- `canetinhas.webp` — Canetinhas coloridas — orientação: 1:1 (ex.: 600×600)
- `cola.webp` — Cola branca — orientação: 1:1 (ex.: 600×600)
- `caderno-dez.webp` — Caderno espiral — orientação: 1:1 (ex.: 600×600)
- `pasta.webp` — Pasta organizadora — orientação: 1:1 (ex.: 600×600)
- `bloco.webp` — Bloco autoadesivo — orientação: 1:1 (ex.: 600×600)
- `lapis-cor.webp` — Lápis de cor — orientação: 1:1 (ex.: 600×600)

- Utilize fotografias com licença compatível com uso comercial e guarde o registro da origem.
- Use `object-fit: cover` e ajuste `object-position` caso precise proteger o enquadramento.
- Não altere alturas de cards nem modifique os códigos de cálculo, formulários e navegação.
- Otimize o WebP e teste tanto em desktop quanto em celular.
- Não represente fotos genéricas como se fossem instalações reais do cliente.
