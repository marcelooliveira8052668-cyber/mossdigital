# Créditos das fotos — Colégio Aurora Prime

Nenhuma fotografia de terceiros foi incorporada. Imagens atuais: placeholders vetoriais produzidos para uso ilustrativo da demo.

Antes de publicar, preencher para cada foto: nome do arquivo, autor, URL da fonte, licença comercial e data de acesso. Quando identificar alunos ou menores de idade, também documentar a autorização de imagem adequada.
