# Capturas das demonstrações

Capturas dos próprios projetos MOSS Digital, sem contas conectadas ou dados reais de clientes.

- Originais capturados em 2880 × 1800 pixels (janela 1440 × 900 com escala 2×).
- Arquivos WebP de 1600 × 1000, sem compressão destrutiva.
- Os cards preservam a proporção e abrem a imagem completa para ampliação.
- `loja.webp` já mostra as fotografias ilustrativas do catálogo atualizado da NEXA Store.

São prévias das demonstrações, não comprovação de clientes, vendas ou resultados reais. Os projetos externos podem mudar depois da captura.
