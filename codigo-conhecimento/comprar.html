Perguntas antes de comprar

O PDF é o livro inteiro?

Sim. O PDF traz o conteúdo completo do livro, do capítulo 0 ao 5, com os exercícios e os gabaritos comentados — exatamente o que você lê aqui, em formato paginado.

Por que pagar se eu consigo ler tudo no site?

A leitura online é de graça e continua disponível — foi para você conhecer o material sem risco. O PDF é a versão para estudar de verdade: paginada, feita para imprimir, para annotate com caneta e para ler offline, no ônibus ou no computador sem internet.

Recebo o livro na hora?

Sim. O download é liberado assim que o pagamento é confirmado e o link chega no seu e-mail. É um produto digital, então não tem frete nem prazo de entrega.

Se eu não gostar, tem reembolso?

Tem. Você tem 7 dias para pedir o reembolso após a compra, conforme o Código de Defesa do Consumidor (art. 49, para compras online). O pedido é feito na própria plataforma de pagamento, sem burocracia.

Posso usar em sala de aula?

Pode. O livro autoriza o uso educacional em atividades de sala de aula, estudos individuais e projetos educacionais, desde que a fonte seja citada. Para uso comercial ou venda de cópias, entre em contato antes.

Preciso saber programar para começar?

Não. O capítulo 0 é exatamente para quem nunca escreveu uma linha de código. Se você já tem noção de HTML e CSS, pode pular direto para o capítulo 4.
