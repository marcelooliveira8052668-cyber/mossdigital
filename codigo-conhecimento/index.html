Capítulo 0 • Antes de começar

Seja bem-vindo ao mundo da programação!

0.1 Este livro é para você

Você não precisa saber nada de programação para ler este livro. Aqui, começamos do absoluto zero.

Se você nunca escreveu uma linha de código, se não sabe o que é uma "tag" ou se nunca ouviu falar em "variável", está no lugar certo. Cada página explica tudo com calma, passo a passo.

0.2 O que é programar?

Programar é dar instruções para o computador. Imagine que você está ensinando um amigo a fazer um bolo: você precisa dizer exatamente o que fazer, em que ordem e com quais ingredientes.

O computador é como esse amigo: ele é muito rápido, mas precisa de instruções muito claras e detalhadas. Se você esquecer um passo, ele não adivinha — ele simplesmente não faz nada ou faz errado.

Pense comigo!

  1. Escreva em uma lista os passos para escovar os dentes.
  2. Leia a lista em voz alta, como se estivesse ensinando uma criança de 5 anos.
  3. Percebeu que precisa falar até para "pegar a escova" e "colocar creme dental"? É assim que o computador funciona.

0.3 Como o computador "pensa"?

O computador entende apenas dois estados: ligado ou desligado. Isso é chamado de binário e usa apenas os números 0 e 1.

Como seria impossível escrever programas inteiros só com 0 e 1, criamos linguagens de programação. Elas são mais parecidas com o nosso idioma e um programa chamado "compilador" ou "interpretador" traduz para o computador entender.

0.4 Preparando o computador

Para escrever código, você precisa de um editor de texto. O mais usado por iniciantes e profissionais é o VS Code, que é gratuito.

  1. Acesse code.visualstudio.com.
  2. Baixe e instale o VS Code para o seu computador (Windows, Mac ou Linux).
  3. Abra o VS Code e crie uma nova pasta chamada "meus-codigos".
  4. Dentro dessa pasta, crie um arquivo chamado ola.html.

Seu primeiro arquivo

  1. Abra o VS Code.
  2. Crie o arquivo ola.html.
  3. Escreva o seguinte código:
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha primeira página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Estou aprendendo a programar.</p>
</body>
</html>
  1. Salve o arquivo.
  2. Clique duas vezes no arquivo para abrir no navegador.
  3. Parabéns! Você criou sua primeira página web.

Dica importante: não se preocupe em decorar tudo de uma vez. Programação se aprende praticando, errando e tentando novamente.

Introdução à programação web

1.1 O que é programação?

Programação é o processo de criar instruções que um computador pode executar para realizar determinadas tarefas.

Essas instruções são escritas utilizando linguagens de programação e seguem regras que permitem ao computador interpretá-las ou executá-las.

1.2 O que é desenvolvimento web?

Desenvolvimento web é a criação e manutenção de sites e aplicações acessados principalmente por navegadores, como Edge, Chrome e Firefox.

1.3 Três tecnologias fundamentais

  • HTML: organiza a estrutura e o conteúdo.
  • CSS: define cores, fontes e layouts.
  • JavaScript: adiciona comportamento e interatividade.

Capítulo 1 • Continuação

Como a web funciona?

1.4 Internet e World Wide Web

A internet é uma grande rede de redes de computadores que se comunicam utilizando protocolos.

A World Wide Web, também chamada de web, é um serviço que utiliza essa infraestrutura para disponibilizar páginas e outros recursos conectados por links.

Isso significa que internet e web não são exatamente a mesma coisa. A internet permite diferentes tipos de comunicação, enquanto a web é uma das maneiras de acessar informações nela.

1.5 Cliente e servidor

O cliente é o programa que solicita um recurso. Quando acessamos um site, normalmente o navegador atua como cliente.

O servidor é o sistema que recebe solicitações e pode responder enviando arquivos, informações ou resultados de processamento.

1.6 O que acontece ao acessar um site?

  1. Eu digito o endereço de um site no navegador.
  2. O navegador identifica como encontrar o servidor correspondente.
  3. O navegador envia uma solicitação HTTP ou HTTPS ao servidor.
  4. O servidor responde com os recursos necessários ou com uma mensagem de status.
  5. O navegador interpreta os recursos recebidos e apresenta a página ao usuário.

Importante: esta é uma explicação simplificada. Na prática, o navegador também pode utilizar cache, executar JavaScript e fazer novas solicitações para carregar outros recursos.

1.7 Meu primeiro exemplo de HTML

O HTML utiliza elementos para organizar o conteúdo de uma página. Observe este exemplo: 

<!-- Eu crio um título principal. -->
<h1>Minha primeira página</h1>

<!-- Eu crio um parágrafo explicativo. -->
<p>Estou aprendendo HTML!</p>

A tag <h1> representa um título principal. A tag <p> representa um parágrafo.

1.10 Como esse programa funciona?

O programa identifica o botão por meio de seu atributo id, acompanha o evento de clique e modifica o texto de um elemento da página.

Capítulo 1 • Lógica de programação

Aprendendo a pensar como um programador

1.11 O que é lógica de programação?

Lógica de programação é a organização de instruções para resolver um problema de maneira clara e ordenada.

Antes de escrever um programa, precisamos compreender o problema, identificar as informações necessárias e planejar os passos que levarão à solução.

1.12 Sequência de instruções

Uma sequência é um conjunto de instruções executadas em determinada ordem. 

// Eu apresento a primeira mensagem.
console.log("Primeiro passo");

// Eu apresento a segunda mensagem.
console.log("Segundo passo");

// Eu apresento a terceira mensagem.
console.log("Terceiro passo");

Nesse exemplo, as mensagens aparecem na ordem em que foram programadas.

1.13 Estruturas condicionais

Uma condição permite que o programa escolha entre diferentes ações.

Em JavaScript, podemos utilizar if para verificar uma condição e else para definir o que acontece quando ela é falsa. 

// Eu guardo a nota do estudante.
const nota = 8;

// Eu verifico se a nota é maior ou igual a 7.
if (nota >= 7) {

    // Eu apresento a mensagem quando a condição é verdadeira.
    console.log("Parabéns! Você foi aprovado.");

// Eu defino a alternativa quando a condição é falsa.
} else {

    // Eu apresento uma mensagem de incentivo.
    console.log("Continue estudando e praticando!");

// Eu encerro a estrutura condicional.
}

Neste exemplo didático, utilizamos a nota 7 como critério de aprovação. Em uma situação real, esse critério depende das regras da instituição de ensino.

1.15 Estruturas de repetição

Uma estrutura de repetição permite executar instruções várias vezes, enquanto uma condição de continuidade for atendida. 

// Eu inicio um contador com o valor 1.
let contador = 1;

// Eu repito as instruções enquanto o contador for até 3.
while (contador <= 3) {

    // Eu apresento o valor atual do contador.
    console.log(contador);

    // Eu aumento o contador em uma unidade.
    contador++;

// Eu encerro o bloco de repetição.
}

O programa apresenta os números 1, 2 e 3. Depois disso, a condição deixa de ser verdadeira e a repetição termina.

Hora de praticar!

  1. Qual é a diferença entre sequência e condição?
  2. O que significa o operador >=?
  3. Quantas vezes o exemplo com while apresenta um número?
Ver gabarito comentado

2. O operador >= significa "maior ou igual a".

3. O exemplo apresenta três números: 1, 2 e 3.

Capítulo 2

HTML: a estrutura de uma página web

2.1 O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto.

HTML é uma linguagem de marcação utilizada para organizar e descrever o conteúdo de páginas web.

Com HTML, podemos identificar títulos, parágrafos, imagens, links, listas, tabelas, formulários e outras partes de uma página.

Atenção: HTML não é uma linguagem de programação. É uma linguagem de marcação, pois descreve a estrutura e o significado do conteúdo.

2.2 O que são tags?

Tags são marcações escritas entre os símbolos de menor e maior. Elas ajudam o navegador a identificar os elementos do documento. 

<!-- Eu crio um título principal. -->
<h1>Minha primeira página</h1>

<!-- Eu crio um parágrafo de texto. -->
<p>Estou aprendendo HTML!</p>

No primeiro exemplo, <h1> é a tag de abertura, o texto é o conteúdo e </h1> é a tag de fechamento.

2.3 Estrutura básica de um documento HTML

<!DOCTYPE html>
<!-- Eu informo que utilizo HTML5. -->

<html lang="pt-BR">
<!-- Eu inicio o documento em português. -->

<head>
    <!-- Eu inicio as configurações do documento. -->

    <meta charset="UTF-8">
    <!-- Eu permito o uso de caracteres acentuados. -->

    <title>Meu primeiro site</title>
    <!-- Eu defino o título da aba do navegador. -->

</head>
<!-- Eu encerro as configurações. -->

<body>
    <!-- Eu inicio o conteúdo visível da página. -->

    <h1>Olá, mundo!</h1>
    <!-- Eu crio um título principal. -->

    <p>Meu primeiro site está funcionando!</p>
    <!-- Eu crio um parágrafo. -->

</body>
<!-- Eu encerro o conteúdo visível. -->

</html>
<!-- Eu encerro o documento HTML. -->

2.4 Entendendo cada parte

  • DOCTYPE: informa ao navegador que o documento utiliza HTML moderno.
  • html: representa o elemento raiz da página.
  • head: reúne informações e configurações sobre o documento.
  • body: reúne o conteúdo principal apresentado ao usuário no navegador.
  • h1: identifica um título principal.
  • p: identifica um parágrafo.

Ver gabarito comentado

1. Utilizaria <h1>, pois ele identifica o título principal.

2. Colocaria o conteúdo dentro de <body>.

3. Utilizaria <p> para escrever um parágrafo descritivo.

Capítulo 2 • HTML semântico

HTML semântico: organizando uma página com significado

2.7 O que significa semântica?

Semântica é o estudo do significado. No desenvolvimento web, HTML semântico significa utilizar elementos que descrevem a função de cada parte do conteúdo.

Por exemplo, uma área de navegação deve utilizar o elemento <nav>, enquanto o conteúdo principal da página deve ser identificado por <main>.

2.8 Por que utilizar HTML semântico?

  • Acessibilidade: facilita a navegação de pessoas que utilizam tecnologias assistivas.
  • Organização: torna o código mais fácil de compreender.
  • Manutenção: facilita futuras alterações no projeto.
  • Interpretação: ajuda navegadores e mecanismos de busca a identificar a estrutura do conteúdo.

2.9 Conhecendo os elementos semânticos

<header>: representa um cabeçalho de página ou seção.

<nav>: identifica uma área importante de navegação.

<main>: identifica o conteúdo principal do documento.

<section>: organiza um grupo temático de conteúdos.

<article>: representa um conteúdo independente, como uma notícia ou publicação.

<aside>: identifica um conteúdo complementar, relacionado ao conteúdo ao redor.

<footer>: representa o rodapé de uma página ou seção.

2.10 Exemplo: página de uma escola

<!-- Eu crio o cabeçalho da escola. -->
<header>
    <h1>Escola do Conhecimento</h1>
</header>

<!-- Eu crio a navegação principal. -->
<nav>
    <a href="#cursos">Cursos</a>
</nav>

<!-- Eu inicio o conteúdo principal. -->
<main>

    <!-- Eu organizo a seção de cursos. -->
    <section id="cursos">

        <h2>Nossos cursos</h2>

        <!-- Eu apresento um curso independente. -->
        <article>
            <h3>Introdução ao HTML</h3>
            <p>Aprenda a estruturar páginas web.</p>
        </article>

    </section>

</main>

<!-- Eu crio o rodapé da página. -->
<footer>
    <p>Escola do Conhecimento — 2026</p>
</footer>

Observe: os elementos semânticos não deixam uma página automaticamente bonita. A aparência visual será trabalhada com CSS.

Capítulo 3

CSS: dando vida às páginas web

3.1 O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata.

CSS é uma linguagem de estilos utilizada para controlar a apresentação visual dos elementos de uma página web.

Com CSS, podemos definir cores, fontes, tamanhos, margens, espaçamentos, bordas e a organização dos elementos em diferentes tamanhos de tela.

3.2 A relação entre HTML e CSS

O HTML descreve a estrutura e o significado do conteúdo. O CSS determina como esse conteúdo será apresentado visualmente.

Exemplo: um título

HTML:

<!-- Eu crio o título principal. -->
<h1>Minha escola</h1>

CSS:

/* Eu seleciono todos os títulos h1. */
h1 {

    /* Eu defino a cor azul. */
    color: blue;

    /* Eu defino o tamanho da fonte. */
    font-size: 32px;

}

3.3 Como funciona uma regra CSS?

Uma regra CSS normalmente possui um seletor e um bloco de declarações. Cada declaração contém uma propriedade e seu valor. 

/* Eu seleciono os parágrafos. */
p {

    /* Eu defino a propriedade e seu valor. */
    color: #243247;

}
  • Seletor: identifica os elementos que receberão o estilo.
  • Propriedade: indica qual característica será modificada.
  • Valor: define como essa característica será apresentada.

3.4 Três formas de utilizar CSS

Podemos aplicar CSS diretamente em um elemento, dentro do documento HTML ou por meio de um arquivo externo.

1. CSS inline

<!-- Eu aplico a cor diretamente ao título. -->
<h1 style="color: blue;">Minha escola</h1>

2. CSS interno

<!-- Eu inicio as regras CSS dentro do HTML. -->
<style>

    /* Eu seleciono os títulos principais. */
    h1 {
        color: blue;
    }

</style>

3. CSS externo

<!-- Eu conecto o arquivo externo de estilos. -->
<link rel="stylesheet" href="css/style.css">

Boa prática: em projetos com várias páginas, o CSS externo costuma facilitar a organização e a manutenção dos estilos. É essa abordagem que utilizamos no Portal da Escola.

3.5 Seletores de elemento, classe e ID

/* Eu seleciono todos os parágrafos. */
p {
    color: #243247;
}

/* Eu seleciono elementos da classe destaque. */
.destaque {
    background-color: #fff3c4;
}

/* Eu seleciono o elemento de ID cabecalho. */
#cabecalho {
    background-color: #10294b;
}

O seletor de elemento utiliza o nome da tag. O seletor de classe utiliza um ponto antes do nome. O seletor de ID utiliza o símbolo de cerquilha (#).

Uma mesma classe pode ser utilizada em vários elementos. Já um ID deve identificar um único elemento dentro do documento.

Capítulo 3 • Estilização visual

Cores, fontes e espaçamentos

3.7 Como as cores funcionam no CSS?

As cores ajudam a organizar visualmente uma interface, destacar informações e criar uma identidade para o projeto.

No CSS, podemos representar cores por nomes, valores hexadecimais e funções como rgb() e hsl().

Exemplo: cores em hexadecimal

/* Eu seleciono o corpo da página. */
body {

    /* Eu defino um fundo azul-escuro. */
    background-color: #10294b;

    /* Eu defino a cor branca para o texto. */
    color: #ffffff;

}

O código hexadecimal começa com o símbolo #. No formato de seis dígitos, os dois primeiros representam a intensidade do vermelho, os dois seguintes a do verde e os dois últimos a do azul.

Paleta de cores do Portal da Escola

#193d68: azul utilizado na navegação.

#f4f7fb: tom claro utilizado no fundo.

#ffffff: branco utilizado em textos e seções.

3.8 Tipografia: a aparência dos textos

Tipografia é a organização visual dos textos. Uma boa escolha de fontes, tamanhos e espaçamentos contribui para a legibilidade e a compreensão do conteúdo. 

/* Eu seleciono os parágrafos. */
p {

    /* Eu defino a família de fontes. */
    font-family: Arial, sans-serif;

    /* Eu defino o tamanho das letras. */
    font-size: 17px;

    /* Eu aumento o espaço entre as linhas. */
    line-height: 1.8;

    /* Eu defino a cor do texto. */
    color: #243247;

}

3.9 Unidades de medida no CSS

O CSS utiliza diferentes unidades para representar tamanhos e distâncias. A escolha da unidade depende do elemento e do comportamento desejado.

  • px: representa uma unidade de referência utilizada para medidas na tela.
  • rem: utiliza como referência o tamanho da fonte do elemento raiz.
  • em: utiliza uma referência relacionada ao tamanho da fonte no contexto da propriedade aplicada.
  • %: representa uma proporção calculada em relação à referência definida para aquela propriedade.

3.10 Margin e padding: qual é a diferença?

A propriedade margin controla o espaço externo ao elemento. Já padding controla o espaço entre o conteúdo e a borda do elemento. 

/* Eu seleciono as seções da página. */
section {

    /* Eu crio 20 pixels de espaço externo. */
    margin: 20px;

    /* Eu crio 30 pixels de espaço interno. */
    padding: 30px;

    /* Eu adiciono uma borda visível. */
    border: 2px solid #193d68;

}

3.11 Entendendo o Box Model

O navegador representa os elementos por meio de caixas retangulares. O modelo de caixa do CSS organiza quatro regiões fundamentais: conteúdo, padding, borda e margem. 

/* Eu seleciono todos os elementos. */
* {

    /* Eu incluo padding e borda no tamanho definido. */
    box-sizing: border-box;

}

Importante: com box-sizing: border-box, a largura e a altura definidas incluem o conteúdo, o padding e a borda. A margem continua sendo externa.

  5. O que representa a unidade rem?
Ver gabarito comentado

2. Margin controla o espaço externo, enquanto padding controla o espaço interno à borda.

3. Font-size determina o tamanho da fonte.

CSS Flexbox

3.25 O que é Flexbox?

Flexbox é um modelo de layout do CSS que permite organizar elementos em linhas ou colunas.

Com Flexbox, podemos alinhar conteúdos, distribuir espaços e construir interfaces que se adaptam melhor a diferentes telas.

Exemplo: imagine três cartões de produtos em uma loja virtual. Com Flexbox, podemos organizá-los lado a lado, mantendo espaços entre eles.

3.26 Minha primeira regra Flexbox

Para ativar o Flexbox, utilizamos a propriedade display: flex; no elemento que contém os itens. 

/* Eu seleciono o contêiner dos cartões. */
.container {
    /* Eu ativo o modelo Flexbox. */
    display: flex;
}

Quando utilizamos display: flex;, os elementos filhos passam a ser organizados como itens flexíveis.

3.27 Flex-direction: escolhendo a direção

A propriedade flex-direction determina a direção principal dos elementos. 

/* Eu organizo os elementos em uma linha. */
.container {
    display: flex;
    flex-direction: row;
}

/* Eu organizo os elementos em uma coluna. */
.container-coluna {
    display: flex;
    flex-direction: column;
}

3.28 Justify-content e align-items

justify-content: distribui os elementos ao longo do eixo principal do Flexbox.

align-items: alinha os elementos no eixo perpendicular ao eixo principal. 

/* Eu crio um contêiner flexível. */
.container {
    /* Eu ativo o Flexbox. */
    display: flex;

    /* Eu centralizo os itens no eixo principal. */
    justify-content: center;

    /* Eu centralizo os itens no outro eixo. */
    align-items: center;

    /* Eu defino um espaço entre os itens. */
    gap: 15px;
}

CSS Grid

Organizando elementos em linhas e colunas

3.31 O que é CSS Grid?

CSS Grid é um sistema de layout que permite organizar os elementos de uma página em linhas e colunas.

Imagine uma página com seis produtos. Podemos organizar esses produtos em três colunas e duas linhas, formando uma grade.

Exemplo do cotidiano: pense em uma estante com várias divisórias. Cada divisória pode receber um objeto. No CSS Grid, organizamos elementos de maneira semelhante, utilizando linhas e colunas.

3.32 Qual é a diferença entre Flexbox e Grid?

O Flexbox trabalha principalmente com a organização em uma direção: linha ou coluna.

O CSS Grid permite definir linhas e colunas ao mesmo tempo. Por isso, é muito útil para layouts com várias áreas.

As duas ferramentas podem ser utilizadas no mesmo projeto. Uma não substitui completamente a outra.

3.33 Minha primeira regra CSS Grid

Para transformar um elemento em um contêiner Grid, utilizamos a propriedade display: grid;. 

/* Eu seleciono o contêiner principal. */
.container {
    /* Eu ativo o sistema CSS Grid. */
    display: grid;
}

Ao ativar o Grid, os elementos filhos passam a ser itens da grade. Podemos então definir como eles serão distribuídos.

3.34 Criando colunas com grid-template-columns

A propriedade grid-template-columns permite definir a quantidade e o tamanho das colunas. 

/* Eu crio uma grade com três colunas. */
.container {
    /* Eu ativo o CSS Grid. */
    display: grid;

    /* Eu crio três colunas de mesma largura. */
    grid-template-columns: 1fr 1fr 1fr;
}

A unidade fr representa uma fração do espaço disponível na grade.

No exemplo, cada coluna recebe uma fração igual do espaço disponível. Portanto, as três colunas ficam com a mesma largura.

3.35 Simplificando com repeat()

Podemos utilizar a função repeat() para evitar repetir o mesmo valor várias vezes. 

/* Eu crio três colunas de mesmo tamanho. */
.container {
    /* Eu ativo o CSS Grid. */
    display: grid;

    /* Eu repito três vezes a medida 1fr. */
    grid-template-columns: repeat(3, 1fr);
}

A expressão repeat(3, 1fr) significa: criar três colunas, cada uma ocupando uma fração igual do espaço disponível.

3.36 Espaçamento entre os elementos

A propriedade gap define o espaço entre as linhas e as colunas da grade. 

/* Eu organizo os cartões em uma grade. */
.container {
    /* Eu ativo o CSS Grid. */
    display: grid;

    /* Eu crio três colunas iguais. */
    grid-template-columns: repeat(3, 1fr);

    /* Eu adiciono espaço entre os cartões. */
    gap: 15px;
}

Design Responsivo

Um site responsivo é aquele que adapta sua organização ao tamanho da tela. Assim, o mesmo conteúdo pode ser visualizado em computadores, tablets e celulares.

O que são Media Queries?

Media Queries são regras CSS que permitem aplicar estilos diferentes conforme as características da tela.

Exemplo prático

/* Eu organizo três colunas no computador. */
.produtos {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

/* Eu adapto o layout para telas pequenas. */
@media (max-width: 600px) {
    .produtos {
        grid-template-columns: 1fr;
    }
}

No computador, os produtos aparecem em três colunas. Em telas de até 600 pixels, eles passam a ocupar uma coluna.

Porque os usuários acessam sites em dispositivos diferentes. Um layout responsivo melhora a leitura, a navegação e a utilização do conteúdo.

Introdução ao React

4.1 O que é o React?

O React é uma biblioteca JavaScript para criar interfaces de usuário. Ela foi desenvolvida pelo Meta (antigo Facebook) e é amplamente utilizada para construir aplicações web modernas.

Com o React, dividimos a interface em pequenas partes chamadas componentes. Cada componente é reutilizável e encapsula sua própria estrutura, aparência e comportamento.

Por que usar o React?

  • Componentes reutilizáveis: escreva uma vez e use em vários lugares.
  • Interface declarativa: descreva como a tela deve ficar e o React cuida de atualizá-la.
  • Ecossistema grande: muitas ferramentas, tutoriais e componentes prontos para usar.
  • Atualizações eficientes: o React atualiza apenas o que mudou na tela.

4.2 Como o React difere do que aprendemos?

No HTML, CSS e JavaScript puro, normalmente manipulamos o DOM diretamente com métodos como document.getElementById() e elemento.textContent.

No React, não precisamos mexer no DOM manualmente. Declaramos como a interface deve aparecer e o React se encarrega de sincronizar com o navegador.

Tarefa JavaScript puro React

Modificar texto elemento.textContent Alterar uma variável de estado
Responder a cliques addEventListener("click") Atributo onClick no elemento

4.4 O que é JSX?

Capítulo 4 • Estado com useState

Estado com useState

4.10 O que é estado?

Estado são dados que podem mudar ao longo do tempo e que afetam o que é exibido na tela. Quando o estado muda, o React re-renderiza o componente automaticamente.

Diferente de props, o estado é mutável e pertence ao próprio componente.

4.11 O hook useState

O useState é um hook do React que permite adicionar estado a componentes funcionais. Hooks são funções que começam com a palavra use. 

import { useState } from "react";

function Contador() {

    // Eu crio um estado chamado "contagem" começando em 0.
    const [contagem, setContagem] = useState(0);

    return (
        <div>
            <p>Contagem: {contagem}</p>
            <button
                onClick={() => setContagem(contagem + 1)}
            >
                Incrementar
            </button>
        </div>
    );
}

A estrutura const [contagem, setContagem] = useState(0) significa:

  • contagem: o valor atual do estado.
  • setContagem: a função para atualizar o estado.
  • 0: o valor inicial do estado.

4.12 Atualizando o estado corretamente

Nunca devemos modificar o estado diretamente. Sempre usamos a função de atualização (como setContagem) para informar o React que algo mudou. 

// ERRADO: modifica o estado diretamente.
contagem = contagem + 1;

// CORRETO: usa a função de atualização.
setContagem(contagem + 1);

Capítulo 4 • Efeitos com useEffect

Efeitos com useEffect

4.14 O que são efeitos colaterais?

Efeitos colaterais são operações que acontecem fora do ciclo normal de renderização do React, como buscar dados de uma API, salvar no localStorage ou configurar temporizadores.

O hook useEffect nos permite executar essas operações de forma controlada. 

import { useState, useEffect } from "react";

function Relogio() {
    const [hora, setHora] = useState(new Date());

    useEffect(() => {

        // Eu crio um temporizador que atualiza a cada segundo.
        const temporizador = setInterval(() => {
            setHora(new Date());
        }, 1000);

        // Eu limpo o temporizador quando o componente some da tela.
        return () => clearInterval(temporizador);

    }, []); // Array vazio: executa apenas uma vez.

    return (
        <div>
            <p>Agora são {hora.toLocaleTimeString()}</p>
        </div>
    );
}

4.15 Dependências do useEffect

O segundo parâmetro do useEffect é um array de dependências. Ele controla quando o efeito deve ser executado novamente.

Comportamento das dependências
Segundo parâmetro Quando executa
[] (vazio) Apenas após a primeira renderização.
[valor] Na primeira vez e sempre que valor mudar.
Não informado Após cada renderização.

4.16 Buscando dados com useEffect

import { useState, useEffect } from "react";

function ListaCursos() {

    const [carregando, setCarregando] = useState(true);

            .then(resposta => resposta.json())

    if (carregando) {
        return <p>Carregando cursos...</p>;

            {cursos.map(curso => (
                <li key={curso.id}>{curso.nome}</li>
            ))}
        </ul>
    );
}

4.18 A prop key

O React exige que cada item de uma lista tenha uma chave (key). A chave ajuda o React a identificar quais itens mudaram, foram adicionados ou removidos, tornando a atualização mais eficiente.

A chave deve ser:

  • Única: não pode se repetir entre irmãos.
  • Estável: não deve mudar entre renderizações.
  • Previsível: idealmente, um ID do banco de dados.
// ERRADO: usar índice como chave quando a lista pode mudar.

    <li key={indice}>{tarefa}</li>

// CORRETO: usar um ID único de cada item.

        evento.preventDefault();

        if (novaTarefa.trim() === "") {
            return;
        }

        const tarefa = {
            id: Date.now(),
            texto: novaTarefa,
            concluida: false

        setNovaTarefa("");

        setTarefas(tarefas.map(tarefa =>
            tarefa.id === id
                ? { ...tarefa, concluida: !tarefa.concluida }
                : tarefa
        ));
    }

    function removerTarefa(id) {
        setTarefas(tarefas.filter(tarefa => tarefa.id !== id));
    }

    return (
        <div className="app">
            <h1>Minhas Tarefas</h1>

            <form onSubmit={adicionarTarefa}>
                <input
                    type="text"
                    value={novaTarefa}
                    onChange={evento => setNovaTarefa(evento.target.value)}
                    placeholder="Nova tarefa..."
                />
                <button type="submit">Adicionar</button>
            </form>

            <ul>
                {tarefas.map(tarefa => (
                    <li
                        key={tarefa.id}
                        style={{ textDecoration: tarefa.concluida ? "line-through" : "none" }}

Capítulo 5 JavaScript Assíncrono

JavaScript Assíncrono com async/await

5.10 Por que async/await?

No capítulo anterior, consumimos uma API usando .then() e .catch(). Funciona muito bem, mas conforme o código cresce, a gente começa a empilhar um .then() dentro do outro. É o famoso formato de pirâmide do doom: quanto mais você precisa, mais fundo fica o buraco. 

// Com .then(): a pirâmide do doom
buscarCursos()
    .then(resposta => resposta.json())
    .then(dados => {
        // Eu preciso dos instrutores também...
        return buscarInstrutores()
            .then(instrutores => {
                // ...e agora preciso montar a tela.
                return montarTela(dados, instrutores);
            });
    })
    .catch(erro => console.error(erro));

A proposta do async/await é escrever o código como se tudo acontecesse uma coisa depois da outra — mas deixando o JavaScript esperar de verdade. O resultado é mais fácil de ler, mais fácil de depurar e muito mais fácil de manter.

5.11 A palavra async

Quando você coloca async antes de uma função, o JavaScript entende que ela pode ter momentos de espera. Isso não muda nada na forma como você escreve a lógica: continua sendo uma linha depois da outra. 

// Eu marco a função como assíncrona.
async function buscarCursos() {
    // O código dentro dela pode esperar.
    const resposta = await fetch("https://api.exemplo.com/cursos");
    const dados = await resposta.json();
    return dados;
}

Repare que a função buscarCursos() agora devolve uma Promise (assim como toda função marcada com async), mas quem chama essa função não precisa se preocupar com .then().

5.12 O comando await

O await é o comando que segura a execução até a Promise ser resolvida. Só depois disso a próxima linha roda. Na prática, é como se o JavaScript dissesse: "espera aqui até eu ter o resultado, e depois continua". 

// Eu seguro a execução até a resposta chegar.
const resposta = await fetch("https://api.exemplo.com/cursos");

// Esta linha só roda DEPOIS que a resposta chegou.
console.log("Chegou a resposta!", resposta.status);

O await só pode ser usado dentro de uma função marcada com async. Se você tentar usar fora, o navegador avisa no console que o await só é válido em async.

5.13 Tratando erros com try/catch

Com async/await, o tratamento de erro fica muito mais natural: usamos try e catch, exatamente como em outras linguagens. Tudo que estiver dentro do try é "tentado"; se algo quebrar, o catch assume. 

async function buscarCursos() {
    try {
        // Eu tento buscar os dados.
        const resposta = await fetch("https://api.exemplo.com/cursos");

        // Eu verifico se a resposta foi de sucesso.
        if (!resposta.ok) {
            throw new Error("Erro ao carregar cursos");
        }

        return await resposta.json();
    } catch (erro) {
        // Aqui eu lido com qualquer erro que possa ter acontecido.
        console.error("Não consegui buscar os cursos:", erro.message);
        return [];
    }
}

Com o await, não existe mais a "pirâmide": o erro que acontecer em qualquer ponto é capturado pelo mesmo catch.

5.15 Várias requisições ao mesmo tempo

Quando as requisições são independentes uma da outra, não faz sentido esperar uma para iniciar a outra. O Promise.all() faz isso: ele espera por todas ao mesmo tempo e só continua quando todas terminarem. 

// Eu disparo as duas requisições ao mesmo tempo.
const [cursos, instrutores] = await Promise.all([
    fetch("https://api.exemplo.com/cursos").then(r => r.json()),
    fetch("https://api.exemplo.com/instrutores").then(r => r.json())
]);

// As duas respostas chegaram. Agora eu monto a tela.
montarTela(cursos, instrutores);

Atenção: o Promise.all() espera todas, mas se uma das requisições falhar, o erro é repassado e você perde as outras também. Quando as requisições são independentes e você quer o resultado de cada uma mesmo que a outra falhe, o Promise.allSettled() é a escolha certa.

5.17 O que são formulários controlados?

Em um formulário controlado, o valor de cada campo é gerenciado pelo estado do React. O React é a "única fonte da verdade" sobre o que está digitado.

Isso permite validar campos, desabilitar botões e submeter dados de forma previsível.

5.20 O problema do prop drilling

Quando passamos props por muitos níveis de componentes, chamamos isso de prop drilling. Isso torna o código difícil de manter.

O useContext resolve isso, permitindo que qualquer componente acesse dados globais sem receber props intermediários.

5.21 Criando e usando um Context

import { createContext, useContext, useState } from "react";

// Eu crio o contexto com um valor padrão.
const TemaContext = createContext("claro");

function App() {
    const [tema, setTema] = useState("claro");

    return (
        <TemaContext.Provider value={tema}>
            <button onClick={() => setTema(tema === "claro" ? "escuro" : "claro")}>
                Alternar tema
            </button>

            <ComponenteFilho />
        </TemaContext.Provider>
    );
}

function ComponenteFilho() {
    // Eu acesso o contexto diretamente, sem props.
    const tema = useContext(TemaContext);

    return <p>Tema atual: {tema}</p>;
}

5.22 O hook useReducer

O useReducer é uma alternativa ao useState para gerenciar estados mais complexos. Ele funciona como o Redux, mas de forma simples e nativa.

Ele recebe uma função redutora e um estado inicial, e retorna o estado atual e uma função dispatch para enviar ações. 

import { useReducer } from "react";

// Eu defino como o estado muda para cada ação.
function reducer(state, action) {
    switch (action.type) {
        case "incrementar":
            return { ...state, contagem: state.contagem + 1 };
        case "decrementar":
            return { ...state, contagem: state.contagem - 1 };
        case "resetar":
            return { ...state, contagem: 0 };
        default:
            return state;
    }
}

function Contador() {
    const [estado, dispatch] = useReducer(reducer, { contagem: 0 });

    return (
        <div>
            <p>Contagem: {estado.contagem}</p>
            <button onClick={() => dispatch({ type: "incrementar" })}>+</button>
            <button onClick={() => dispatch({ type: "decrementar" })}>−</button>
            <button onClick={() => dispatch({ type: "resetar" })}>Resetar</button>
        </div>
    );
}

5.24 O hook useMemo

O useMemo memoriza o resultado de um cálculo caro, evitando recalcular desnecessariamente a cada renderização. 

import { useState, useMemo } from "react";

function ListaFiltrada() {
    const [filtro, setFiltro] = useState("");
    const produtos = [
        { id: 1, nome: "Notebook" },
        { id: 2, nome: "Mouse" },
        { id: 3, nome: "Teclado" }
    ];

    const produtosFiltrados = useMemo(() => {
        return produtos.filter(p =>
            p.nome.toLowerCase().includes(filtro.toLowerCase())
        );
    }, [filtro, produtos]);

    return (
        <div>
            <input
                value={filtro}
                onChange={e => setFiltro(e.target.value)}
                placeholder="Buscar..."
            />

            <ul>
                {produtosFiltrados.map(p => (
                    <li key={p.id}>{p.nome}</li>
                ))}
            </ul>
        </div>
    );
}

5.25 O hook useCallback

O useCallback memoriza uma função, evitando que ela seja recriada a cada renderização. É útil ao passar funções como props para componentes otimizados com React.memo. 

import { useState, useCallback } from "react";

function Botao({ aoClicar }) {
    return <button onClick={aoClicar}>Clique</button>;
}

function App() {
    const [contagem, setContagem] = useState(0);

    const lidarComClique = useCallback(() => {
        console.log("Botão clicado!");
    }, []);

    return (
        <div>
            <p>Contagem: {contagem}</p>
            <button onClick={() => setContagem(c => c + 1)}>+</button>
            <Botao aoClicar={lidarComClique} />
        </div>
    );
}

  2. Use useMemo para filtrar uma lista grande de produtos.

5.28 Contexto de tarefas

import { createContext, useContext, useReducer } from "react";

const TarefaContext = createContext();

function tarefaReducer(state, action) {
    switch (action.type) {
        case "ADICIONAR":
            return [...state, action.tarefa];
        case "ALTERNAR":
            return state.map(t =
                t.id === action.id ? { ...t, concluida: !t.concluida } : t
            );
        case "REMOVER":
            return state.filter(t => t.id !== action.id);
        default:
            return state;
    }
}

export function TarefaProvider({ children }) {
    const [tarefas, dispatch] = useReducer(tarefaReducer, []);

    return (
        <TarefaContext.Provider value={{ tarefas, dispatch }}>
            {children}
        </TarefaContext.Provider>
    );
}

export function useTarefas() {
    return useContext(TarefaContext);
}

Capítulo 6 • Versionamento

O que é versionamento?

6.1 O problema de salvar vários arquivos

Já aconteceu de você salvar um arquivo com nomes como projeto-final.html, projeto-final-v2.html e projeto-final-definitivo.html?

Sem um sistema de versionamento, fica difícil saber qual é a versão mais recente, o que mudou entre uma e outra e como voltar para uma versão anterior se algo der errado.

6.2 O que é o Git?

O Git é um programa que registra todas as mudanças que você faz nos seus arquivos. Pense nele como um "salvar jogo" automático: você pode voltar para qualquer ponto anterior se precisar.

Cada vez que você salva uma versão importante, isso se chama um commit (ou "confirmação"). Cada commit tem uma mensagem descrevendo o que mudou.

Sem Git vs Com Git
Sem Git Com Git
Vários arquivos com nomes confusos Um único projeto com histórico
Difícil saber o que mudou Veja exatamente o que mudou em cada versão
Medo de apagar algo importante Volte para qualquer versão anterior
Difícil trabalhar em equipe Várias pessoas trabalham no mesmo projeto

6.3 O que é o GitHub?

Se o Git fica no seu computador, o GitHub é um site na internet onde você guarda seus projetos do Git. É como um "Dropbox para código", mas muito mais poderoso.

No GitHub, você pode:

  • Salvar seus projetos na nuvem.
  • Mostrar seu trabalho para outras pessoas.
  • Ver projetos de outras pessoas e aprender com eles.
  • Trabalhar em equipe no mesmo projeto.

Hora de praticar!

  1. Crie uma conta gratuita no GitHub (github.com).
  2. Baixe e instale o Git no seu computador (git-scm.com).

Dica: o Git é uma ferramenta profissional. Mesmo que você esteja começando agora, aprender a usá-lo cedo fará uma grande diferença.

Capítulo 6 • Comandos

Comandos básicos do Git

6.4 Iniciando um repositório

Um repositório é a pasta onde o Git fica de olho nas mudanças. Para começar a usar o Git em um projeto, rode este comando no terminal dentro da pasta do projeto: 

# Eu inicio o Git nesta pasta.
git init

6.5 O ciclo de vida de um arquivo

No Git, um arquivo passa por três estados:

  • Modificado: você alterou o arquivo, mas ainda não salvou no Git.
  • Staged (preparado): você marcou o arquivo para ser salvo na próxima versão.
  • Commitado: o Git salvou uma versão permanente do arquivo.

6.6 Os comandos principais

# Eu veja o status dos arquivos (modificados, prontos, etc.)
git status

# Eu adiciono um arquivo específico para a próxima versão.
git add nome-do-arquivo.html

# Eu adiciono todos os arquivos modificados.
git add .

# Eu salvo a versão com uma mensagem descritiva.
git commit -m "Minha primeira versão do projeto"

# Eu vejo o histórico de versões.
git log

6.7 Exemplos de mensagens de commit

As mensagens de commit devem ser claras e curtas. Veja exemplos bons e ruins:

Mensagens de commit
❌ Ruim ✅ Bom
git commit -m "atualizou" git commit -m "Adiciona formulário de contato"
git commit -m "fix" git commit -m "Corrige erro no menu mobile"
git commit -m "v2" git commit -m "Cria página de cursos com CSS Grid"

Hora de praticar!

  1. Abra o terminal na pasta do seu projeto.
  2. Rode git init.
  3. Rode git status para ver os arquivos.
  4. Rode git add . para preparar tudo.
  5. Rode git commit -m "Primeira versão do meu projeto".
Ver gabarito comentado

1. O terminal é o programa onde você digita comandos diretamente para o computador.

2. O git init cria uma pasta oculta chamada .git que guarda todo o histórico.

3. O git commit -m é o comando mais importante: ele grava sua versão com uma mensagem.

6.10 O que cada comando faz?

  • git push -u origin main: envia ("push") seus commits locais para o GitHub.

Capítulo 6 • Trabalho em equipe

Trabalhando em equipe

6.11 Por que trabalhar em equipe?

Desenvolvimento web raramente é feito sozinho. Equipes de desenvolvedores trabalham juntas no mesmo projeto, cada uma em uma parte diferente.

O Git e o GitHub permitem que várias pessoas editem os mesmos arquivos sem sobrescrever o trabalho umas das outras.

6.12 Pull Request: propondo mudanças

Quando alguém quer mudar algo no projeto, não edita direto na versão principal. Em vez disso, cria uma branch (ramificação) separada, faz as mudanças e então abre um Pull Request (PR).

O Pull Request é como dizer: "Ei, eu fiz essas melhorias. Você pode revisar e aceitar no projeto principal?" 

# Eu crio uma nova branch para minha tarefa.
git checkout -b minha-melhoria

# Eu faço as mudanças nos arquivos...

# Eu preparo e salvo a versão.
git add .
git commit -m "Adiciona página de sobre"

# Eu envio a branch para o GitHub.
git push -u origin minha-melhoria

6.13 Clonando um projeto existente

Se quiser trabalhar em um projeto que já existe no GitHub, você pode fazer uma cópia completa no seu computador com o comando clone: 

# Eu faço uma cópia do projeto no meu computador.
git clone https://github.com/usuario/projeto.git

6.14 Atualizando seu projeto com mudanças dos outros

Se alguém mais enviou mudanças para o GitHub, você pode baixá-las para o seu computador com: 

# Eu baixo as mudanças mais recentes do GitHub.
git pull

Hora de praticar!

  1. Peça para um colega adicionar você como colaborador em um repositório.
  2. Clone o repositório no seu computador.
  3. Crie uma branch, faça uma mudança e envie um Pull Request.

Lembre-se: antes de enviar um Pull Request, sempre baixe as mudanças mais recentes com git pull para evitar conflitos.
