# Gerador de Portfólio

Ferramenta para **quem cria site para cliente**: você preenche umas caixas, escolhe as cores e o portfólio fica pronto — responsivo, com tema escuro, acessível e com prévia de rede social.

**Um arquivo só. Sem instalação, sem servidor, sem build.**

🔗 Demonstração: <https://marcelooliveira8052668-cyber.github.io/gerador-portfolio/>

---

## O que tem nesta pasta

| Arquivo | Para que serve |
|---------|----------------|
| `GERADOR.html` | **É este que você abre.** O gerador propriamente dito. |
| `exemplo-cliente/` | Um site já pronto, feito com o gerador, com as fotos. Serve de referência. |
| `COMO-USAR.md` | Passo a passo em português simples, do primeiro clique até a entrega. |
| `CROQUI.html` | O caminho inteiro em 6 etapas, em forma de desenho. |
| `PUBLICAR.md` | Como colocar no ar (Netlify, GitHub Pages) e a lista de conferência. |
| `index.html` | A página de venda do gerador. |

> **Nunca abra o `GERADOR.html` com Word ou Google Docs.**
> Word salva com sujeira invisível e estraga o arquivo. Abra com o
> **Bloco de Notas** ou, melhor ainda, dê dois cliques no arquivo.

---

## Como funciona em 5 passos

1. **Abra o gerador** — dois cliques no `GERADOR.html`.
2. **Preencha** o que o cliente te deu: nome, profissão, WhatsApp, serviços.
3. **Escolha as cores** — um conjunto pronto ou cinco seletores. O resto é calculado.
4. **Baixe o site** — um arquivo `index.html`. É o que o cliente recebe.
5. **Coloque no ar** — arraste a pasta no [Netlify Drop](https://app.netlify.com/drop).

O `CROQUI.html` mostra o caminho inteiro em forma de desenho.

## O que o site gerado já sai com

- **Responsivo** de fábrica, testado em tela pequena
- **Tema claro e escuro**, alternável pelo visitante, com as duas versões consistentes
- **Ícone de aba** com as iniciais do cliente
- **Prévia de rede social** (WhatsApp, Instagram, Facebook) com nome, frase e foto
- **Acessibilidade**: botão de pular para o conteúdo, foco visível no teclado
- **Aviso de contraste** automático, quando a escolha de cor deixa o texto ruim
- Campos vazios **somem** em vez de mostrar "undefined"
- Proteção contra aspas e barras no texto
- Redimensionamento automático de tela para celular

---

## As 5 cores

O gerador não é só "escolher uma cor". Ele calcula sozinho:

- o tom clarinho do destaque
- as linhas e bordas
- as duas cores de texto secundário
- as sombras
- o brilho do topo da página
- e o **tema escuro inteiro**

Por isso, se você mexer só na cor principal, o site continua bonito nos dois temas.

Conjuntos prontos: **Terracota, Rosa, Lilás, Azul, Verde, Vinho, Preto e dourado**.
