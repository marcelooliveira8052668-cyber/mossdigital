# NextTech — Site de Assistência Técnica

Site institucional responsivo para assistência técnica de notebooks e computadores de mesa.
Feito em HTML, CSS e JavaScript puro — **não precisa instalar nada**.

## Como abrir

Dê um duplo clique em `index.html` ou abra o arquivo no navegador.
Para publicar na internet, envie esta pasta inteira para qualquer hospedagem (ex.: Netlify, Vercel, Hostinger).

## Estrutura

```
assistencia-tecnica-site/
├── index.html          # conteúdo e seções do site
├── css/style.css       # cores, layout e responsividade
├── js/script.js        # menu mobile, animações, contadores e formulário
├── images/             # fotos reais (Unsplash)
└── README.md
```
