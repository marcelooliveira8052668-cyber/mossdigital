Preciso saber programar?

Não. Comece pelos fundamentos e lógica. Os capítulos avançados são complementares: não precisam ser dominados antes de construir sua primeira página.

O livro só serve para hamburgueria?

Não. A hamburgueria é o projeto condutor. HTML, CSS e lógica se aplicam a outros sites, mas agenda, estoque, atendimento e pagamentos exigem regras específicas de cada negócio.

O PDF pode ser lido em celular ou computador. Para a maioria das práticas, recomendamos um computador com editor e navegador. A versão HTML pode ser aberta localmente no computador. Instalação de pacotes, APIs e serviços externos podem exigir internet.
