⚠
Abra por um servidor, não pelo ícone do arquivo

Você abriu o index.html direto do disco (file://). Por segurança, o navegador bloqueia os módulos que este app usa — por isso os botões não respondem.

Jeito rápido de ver funcionando: instale a extensão Live Server no VS Code, clique com o botão direito no index.html e escolha Open with Live Server.

Ou abra a versão já publicada: marcelooliveira8052668-cyber.github.io/SkillMatch-web
